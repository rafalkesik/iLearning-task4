# README

This project is part of iLearning Ruby program by Itransition.

## How to run this project locally?

1. Install Ruby version 3.3.6.
2. Setup
```bash
gh repo clone rafalkesik/iLearning-task4
cd iLearning-task4
bundle install
bin/rails db:setup
```
3. Run the app
```bash
rails server
```
4. Open http://localhost:3000.
